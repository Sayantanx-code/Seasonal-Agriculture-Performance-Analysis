# 🌾 Seasonal Agriculture Performance Analysis

## 📌 Project Overview

**Seasonal Agriculture Performance Analysis** is a data analytics and machine learning project that evaluates agricultural performance across **Kharif, Rabi, and Zaid seasons**. The project analyzes crop yield, profitability, water efficiency, resource usage, environmental conditions, and disease/pest risk to identify important agricultural patterns and support data-driven decision-making.

The project combines **data preprocessing, exploratory data analysis, statistical testing, visualization, correlation analysis, and machine learning** to transform agricultural data into meaningful insights.

---

## 🎯 Objectives

* Analyze agricultural performance across different seasons.
* Compare crop yield and profitability.
* Identify high- and low-performing crop-season combinations.
* Analyze water and other resource utilization.
* Study relationships between environmental factors and yield.
* Evaluate disease and pest risk across seasons.
* Compare agricultural performance across states.
* Build a machine learning model for yield prediction.
* Generate data-driven agricultural recommendations.

---

## 📊 Key Findings

* **Kharif** shows the strongest overall performance in the dataset.
* Kharif records the highest average **yield, profit per hectare, and water efficiency**.
* **Zaid** shows comparatively weaker economic performance with negative average profitability.
* **Sugarcane and Chilli** are among the highest-profit crop-season combinations.
* Water usage has the strongest observed correlation with yield (**0.48**).
* Kharif has higher disease/pest risk, highlighting the need for better risk management.
* Agricultural performance varies significantly across **crops, seasons, and states**.

## 📈 Analysis Performed

### 1. Data Preprocessing

* Dataset structure and data types
* Missing-value analysis
* Duplicate detection
* Data validation
* Data cleaning

### 2. Feature Engineering

Created analytical features including:

* Profit per hectare
* Revenue per hectare
* Water usage per hectare
* Total NPK

### 3. Exploratory Data Analysis

Analyzed:

* Seasonal yield
* Crop profitability
* Water efficiency
* Resource consumption
* Disease/pest risk
* Environmental conditions

### 4. Statistical Analysis

Applied:

* ANOVA
* Kruskal-Wallis test
* Mann-Whitney pairwise testing
* Bonferroni correction
* Effect-size analysis

### 5. Correlation Analysis

Investigated relationships between:

* Water usage and yield
* Rainfall and yield
* Soil moisture and yield
* Fertilizer and yield
* Temperature and yield
* Disease/pest risk and yield

### 6. Machine Learning

A **Random Forest Regression** model was developed to predict agricultural yield and identify important predictive features.
